# Silicon Photonics and 2D Material Integration

**SJTU Research Exchange · March–July 2026 · Zhang Jinming**  
**Host supervisor: Prof. Ciyuan Qiu · NTU supervisor: Prof. Zheng Liu**

My exchange work covered 2D-material photonic devices, graphene heaters, microring-array computing experiments and exploratory magneto-optic design. My contributions included material transfer, optical setup assembly and alignment, electrical/optical testing and device troubleshooting.
